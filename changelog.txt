- Added GlobeWidget as Subscriber instead of Satellite
- Changed satellites dict to spaceObjects dict
- Added various variables for AdjacencyMatrix, mouse tracking, 2D point projection, hover functions, camera controls.

- Added Camera based controls 
- Added a rotation to earth to align satellite orbits with correct positions based on online trackers. Satellite positions aren't in the correct place due to time being calculated by 86400 instead of 86160 and tle data being 2 months old when tle data is really inaccurate past 2 weeks old.
- Changed base satellite draw to incorporate both satellites and ground stations.
- Added function to add hardcoded ground Stations.
- Added function to generate 2D point projection for space objects and earth model for hover function.
- Added Mouse control to simulation, including:
	Right Click: Toggle Orbit
	Left Click Drag: Camera Pan
	Scroll: Zoom
	MouseMove: Hover
- Added Helper function for debugging position in simulation
- Added function to update all SpaceObjects. Steps:
	1. Check if tle_data exists
	2. Add new satellites from tle_data
	3. Delete satellites if not in tle_data
	4. Change satellite show value based on tle_status
	5. Update satellite position based on the current time with utc offset.
	6. Generate Adjacency matrix of all (can work for all, but currently only does satellites) SpaceObjects.
